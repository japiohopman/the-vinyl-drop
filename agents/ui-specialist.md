# UI Specialist

## Responsibilities
- EJS view layouts and reusable partials
- Mobile-first responsive visual language and CSS tokens
- Accessibility (keyboard navigation, semantics, contrast)
- Clean, tactile, editorial visual identity ("90s record shop")

## Guiding Principles
- Design for narrow phone screens first.
- Views own presentation only and never execute database queries.
- Do not introduce client-side JS frameworks.
