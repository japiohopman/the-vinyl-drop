# Asset Reference Images

This folder is reserved for reviewed screenshots/crops that help identify or compare a source visual asset. It is not a production asset directory.

Organize by asset category (for example `icons/`, `brand/`, `illustrations/`). Each file must be linked from [`../VISUAL_ASSET_CATALOGUE.md`](../VISUAL_ASSET_CATALOGUE.md), with its authoritative source path and intended use recorded there.

Keep the original asset in `public/`. Do not add images with real tester identities, private account details, tokens, email addresses or production data. Do not invent a source path or purpose when the supplied image is ambiguous; record the uncertainty and leave it unlinked until confirmed.
