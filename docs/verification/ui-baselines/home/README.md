# Home Visual References

This folder is the canonical location for the Home surface.

Expected reference filenames:

- `home-desktop.png`
- `home-mobile.png`

The current `home_desktop.png` placeholder in the repository is zero bytes and is not a usable screenshot. It should be replaced with the approved Home desktop capture. No valid Home mobile capture is present yet.

When adding images, record their viewport, route (`/`), visible state, theme, staging capture date and application commit (when available) in [`../UI_VISUAL_REFERENCE.md`](../UI_VISUAL_REFERENCE.md). Do not add duplicate crops or every viewport permutation.
