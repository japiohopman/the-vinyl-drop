# Browse Visual References

This folder is the canonical location for the desktop Browse reference.

The owner-confirmed coverage model for this library is:

- **Desktop reference:** Browse (`/browse`), stored here as `browse-desktop.png`.
- **Mobile reference:** Dig (`/dig`), stored in [`../dig/`](../dig/) as `dig_mobiel.png`.

These are the intended desktop/mobile reference pair for the current discovery experience. Do not request an additional desktop Dig or mobile Browse capture unless a future UI issue specifically changes or separates those experiences.

The previous `dig_desktop.png` entry in this folder was a zero-byte placeholder and has been removed. The current historical desktop Browse reference lives at [`../../desktop_browse_list_1280x800.png`](../../desktop_browse_list_1280x800.png). Keep that source linked rather than duplicating it. When a newer Browse reference is intentionally captured, add it here as `browse-desktop.png` and update the central index.

When adding it, record the viewport, route, state, theme, staging capture date and application commit (when available) in [`../UI_VISUAL_REFERENCE.md`](../UI_VISUAL_REFERENCE.md).
