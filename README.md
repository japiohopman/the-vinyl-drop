# The Vinyl Drop

A local community marketplace for buying, selling, and trading physical records.
A small start. based in Amsterdam Oost.

The project is designed mobile-first and developed through an Issue-driven agentic workflow using GitHub Actions, Jules, specialist agents, automated verification, and human review.

## Documentation

The product vision, domain model, data architecture, technical architecture, UX/UI, security, roadmap, agentic workflow, decisions, and pre-launch operations are documented in [docs/](./docs/).
